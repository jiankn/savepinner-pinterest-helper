Image resolution and print size checker

Enter pixel dimensions to check whether an image needs enlargement for a target screen and to estimate effective print DPI. This calculator reads no files and sends no data. For images you are permitted to save, the project maintains the Pinterest image downloader.

How to interpret the result
A scale below 1 means the source is smaller than at least one target dimension and would need enlargement. Effective print DPI is pixels divided by physical inches; the lower axis limits the result. A ratio mismatch means cropping, letterboxing or a different print size is needed. DPI alone does not prove sharpness, authenticity, permission, or that a file is the original upload.
Check dimensions after decoding the actual image. A filename containing HD does not establish pixel size, and changing the extension cannot add detail. Keep an untouched source copy before cropping or resampling.
