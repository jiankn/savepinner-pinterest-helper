SavePinner Pinterest Helper

A small browser helper for copying canonical Pinterest Pin URLs, detecting public media metadata, and continuing a download in SavePinner when needed.

Install from Greasy Fork View source on GitHub

Install

  1. Install Tampermonkey or Violentmonkey in your browser.
  2. Open the Greasy Fork page above and choose Install this script.
  3. Visit a Pinterest Pin page and select the red SP button.

What it does

  • Copies a clean, canonical Pin URL.
  • Copies public image or video URLs exposed in page metadata.
  • Handles Pinterest's client-side navigation without a page refresh.
  • Routes image Pins to the Pinterest image downloader, video Pins to the Pinterest video downloader, and unknown media types to the general downloader—only after an explicit click.

Privacy

The helper runs locally in the browser. It contains no analytics, remote code, or external assets, and it does not transmit browsing history.

Development

Clone the repository and run npm test to validate the userscript metadata and syntax.
