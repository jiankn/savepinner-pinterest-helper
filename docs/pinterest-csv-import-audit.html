Audit Pinterest links before a CSV import

This local Python integration classifies each CSV row, preserves the original fields and marks repeated normalized URLs. It makes no URL fetches and does not discard duplicates. A separate permitted image workflow can use the Pinterest image downloader after confirming a public image Pin.

Install and run

Use Python 3.10 or newer in a virtual environment. Download the MIT-licensed audit script.

python -m pip install pinterest-url-normalizer==0.1.2
python pinterest_csv_audit.py input.csv result.jsonl
python pinterest_csv_audit.py input.csv result.jsonl --column source_url

The CSV requires a unique header row and a URL column. UTF-8 with or without BOM and quoted fields are supported. Output must be a new file. Test on a small export first: records are held in memory, so this helper is intended for bounded local batches.

Read the output

Every data record produces one JSON line with its record number and original fields. Classified rows include kind, normalized_url, duplicate_of and media_verified=false. Invalid rows retain their source and diagnostic error. Duplicate references point to the first matching record; normalization is a grouping hint, not permission to delete source records.

Route deliberately

Pin syntax does not prove availability or image type. Short links need a separate resolver; boards, profiles and Ideas pages need their own handling. Never treat every valid Pinterest URL as one image. Preserve source context and rights evidence outside this public example.

Verification

Tested against the published Python package 0.1.2: seven input records, quoted commas, UTF-8 BOM, regional-host normalization, duplicate references, short and board classification, lookalike host rejection, empty input, malformed column counts, existing-output protection and duplicate-header rejection.

JSON Lines preserves text values without converting them to spreadsheet formulas. If exporting these records back into a spreadsheet, apply that exporter's formula-injection policy. Do not publish an output containing private source records.
