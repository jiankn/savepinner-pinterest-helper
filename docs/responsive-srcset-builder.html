Responsive image srcset builder

Generate width-descriptor srcset markup from image URLs and their actual decoded pixel widths. The data stays in this browser tab. For images you are permitted to acquire, the project maintains the Pinterest image downloader.

Enter one candidate per row. Use the intrinsic width in pixels, not a target display width or an unverified filename.

Markup will appear here.

Before using the result

Confirm every URL returns an image that decodes successfully and that each width descriptor matches the real candidate width. Provide truthful sizes, intrinsic dimensions, alt text, and a suitable fallback src. This tool does not fetch or verify remote URLs and cannot prevent a server from changing its response.
