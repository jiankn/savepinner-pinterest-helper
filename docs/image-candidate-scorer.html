This worksheet ranks already discovered candidates; it does not fetch Pinterest pages or images. Always verify the winning response's content type, signature, dimensions, and final host.

When to compare results

If an integration still returns an avatar or thumbnail, compare the same public Pin with a browser-based Pinterest image downloader. A mismatch helps isolate candidate discovery, scoring, or asset validation.

Scoring model

  • Primary structured data receives the strongest source weight.
  • Verified pixel area adds a bounded quality signal.
  • Avatar-sized squares, related content, and non-HTTPS URLs receive penalties.
  • The score is diagnostic guidance; the final response must still decode as an image.
