Local file checksum manifest

Select saved image files to create a SHA-256 inventory and flag exact duplicate candidates. Files are read locally in this browser tab; this tool contains no upload or analytics requests. For permitted image acquisition, the project maintains the Pinterest image downloader.

The exported manifest contains filenames, byte lengths, modification times and hashes. Review it before sharing; filenames may disclose personal information. It does not record source Pin URLs or establish permission to reuse an image.

Limits and review

This checks file bytes, not visual similarity or image validity. Recompressed copies will have different hashes. Duplicate candidates are never deleted. Files larger than 50 MiB are skipped to limit memory use; a file is loaded in full for the browser hashing operation. Two files with the same name remain distinct records.

Keep the originals and associate a source URL separately when known. Before deleting anything, compare candidate bytes and preserve a reversible backup. Downloading a file does not transfer copyright.
