MCP response inspector

Paste a SavePinner MCP tool result or JSON-RPC response. This tool checks its shape locally; it does not contact a server, validate domain ownership or retrieve media. If a separate permitted workflow confirms an image Pin, the project provides the Pinterest image downloader.

Interpret the boundary

A successful tool call can recognize a board, profile or short link. Those results do not identify a downloadable image. Even a Pin classification establishes URL syntax only. This inspector never marks a result download-ready.

Protocol errors, tool execution errors and unsupported URLs require different handling. Use structuredContent when available; a text block may contain prose or an error message. Avoid pasting tokens or personal data. Clearing the field removes this tab's displayed input; no localStorage or network requests are used.
