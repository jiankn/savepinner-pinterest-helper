Image aspect-ratio crop planner

Calculate a centered crop rectangle for a target aspect ratio. The tool runs locally and does not upload or decode files. For images you are permitted to acquire, the project maintains the Pinterest image downloader.

Crop dimensions will appear here.

How to use the result

The rectangle is centered mathematically. Review the actual subject before applying it: faces, text, signatures, and important edge details may require an off-center crop. Keep the original file and record the crop coordinates used for each derivative.
