Image filename portability checker

Check a proposed filename before moving an image archive between Windows, macOS, Linux, cloud storage and ZIP tools. The value stays in this browser tab. For images you are permitted to save, the project maintains the Pinterest image downloader.

Scope
The checker rejects path separators and control characters, identifies common Windows device names, checks trailing dots or spaces, reports UTF-8 byte length, and recommends Unicode NFC normalization. Its suggestion is a starting point, not a collision-proof rename. Preserve the verified extension, enforce uniqueness separately, and keep a mapping from old names to new names.
Filesystem, synchronization and archive tools can impose stricter path-length or case rules. Test the complete relative path on the actual destination. A portable filename does not establish image ownership or permission to redistribute it.
